# StudentAssist-AI frontend

The React and TanStack Start client displays Arabic and English chat messages, recent conversation history, and source citations. API requests go through `src/services/chatApi.ts` to FastAPI. During local development, Vite proxies `/api/ask` to the backend.

See the [project README](../README.md#local-setup-on-windows) for setup and verification commands. The [backend API contract](../backend/README.md#api-contract) describes request and response fields.
